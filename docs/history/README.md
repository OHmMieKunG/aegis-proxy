# Historical documentation

Files here preserve dated repository evidence and decisions. They are not current implementation
status or current test results. Use [`STATUS.md`](../../STATUS.md) and [`PLAN.md`](../../PLAN.md).

- `implementation/`: original greenfield plan, readiness review, phase 0–13 completion reports.
- `validation/`: dated crash-recovery, Elysium, and repository-documentation audit reports.
- `security/`: dated release-candidate evidence and tabletop exercise.

Historical claims remain scoped to their recorded commit, environment, tools, and limitations.
